# What it takes to sell this (honest status, October 2026)

## Ready now
Workspace with agents, council, brain, research, MCP apps, self-test and evidence link; presets; plans and limits; Stripe code; leads and funnel counters; trust page; production basics (readiness, keys, backups, logs).

## Missing before the first paid customer (in this order)
1. **A real deployment you operate** (persistent volume, HTTPS, your domain) and one full test purchase in Stripe test mode.
2. **Legal documents** (docs/LEGAL-TEMPLATES.md). Buyers ask for a DPA and a sub-processor list before a pilot.
3. **One reference**: a design-partner pilot with a written outcome, even if anonymized.
4. **The paid test product**: a pilot report against a customer's own agent endpoint (planned next). Until then the self-test only covers this app.
5. **SSO and multi-tenant hosting** are asked for by larger buyers. Not needed for the first five pilots.
6. **SOC 2 Type I roadmap**: start the evidence collection early; it takes months. Say "in progress" only when true.

## Pricing hypotheses to test (not facts)
Free (capped) to try, Pro EUR 19 for one person, Team EUR 99 for a small team, Pilot invoiced. Large chat products price a capped free tier, a roughly USD 20 plan and a high-end plan; your edge is evidence and control, so price the pilot, not the chat.

## First ten customers
- Target fintech and security teams that already run or plan agents. Offer: free pilot setup, an evidence report in two weeks, EUR 1,000 to 3,000 for the full authorization test afterwards.
- Use /welcome, the sample evidence table and the self-test link as the opener; track page views, pilot clicks and leads in Control > Pipeline.
- After each pilot: ask for a quote, the report (anonymized) and one introduction.

## Measure
Visitors to leads, leads to pilots, pilots to paid, time to first council call, share of workspaces that run the self-test.
